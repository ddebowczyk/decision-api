# ScaleDown: Classify-1

[scaledown](https://openrouter.ai/scaledown)/classify-1

[Compare](https://openrouter.ai/compare/scaledown/classify-1)API

Classify-1 is a structured decision model from ScaleDown, served through OpenRouter's Decisions API. It scores text or a document against caller-defined choice, yes/no, and ordered-scale questions and returns calibrated probabilities rather than generated prose, making it suited for routing, moderation, intent detection, and domain tagging inside an application. It is request-compatible with TypeSafe's Jev Decisions API.

Learn more in ScaleDown's docs: [https://docs.scaledown.ai/api-reference/decisions-overviewOpens in new tab](https://docs.scaledown.ai/api-reference/decisions-overview)

## Providers

This model is hosted by one provider. OpenRouter forwards every request to it directly — no routing decisions to make.

## Pricing

The average price customers actually pay for this model, next to the prices providers post. Caching and discounts mean the price actually paid is often well below the listed one.

## Performance

Throughput is how fast the model writes (tokens per second — higher is better). Latency is total round-trip time (lower is better). TTFT is time-to-first-token — how long before you see anything appear (lower is better).

## Uptime

Uptime is the percentage of the past 3 days that at least one provider was responding to requests. Availability is the percentage of time that inference was successfully served. OpenRouter continuously monitors and uses the next-best provider when one returns an error.

## Apps

Public apps that send the most traffic to this model. Good signal for what real production workloads look like — and a hint at which use cases this model is best suited for.

## Activity

Token volume and request traffic to this model over time.

## API

Drop-in code to call this model. It runs on the OpenRouter Decisions API rather than the OpenAI-compatible chat endpoint, so the request and response shapes below are specific to structured decisions — chat completions SDKs will not work with it.

Not currently available through EU in-region routing. [In-region routing docs](https://openrouter.ai/docs/guides/features/in-region-routing)

## Frequently asked questions

### What is Classify-1?

Classify-1 is a structured decision model from ScaleDown, served through OpenRouter's Decisions API. It scores text or a document against caller-defined choice, yes/no, and ordered-scale questions and returns calibrated probabilities rather than generated prose, making it suited for routing, moderation, intent detection, and domain tagging inside an application.

### Where is the Classify-1 documentation?

The Classify-1 documentation on OpenRouter includes the [Detect Stuck and Looping Agents with ScaleDown Classify](https://openrouter.ai/docs/cookbook/building-agents/detect-agent-loops-with-scaledown) cookbook. The [quickstart](https://openrouter.ai/docs/quickstart) covers API keys and your first request, and the [API reference](https://openrouter.ai/docs/api-reference/overview) lists every parameter.

### How much does Classify-1 cost?

Classify-1 costs $0.04/M input tokens and $0.00/M output tokens.

### What is the context length of Classify-1?

Classify-1 has a 1,000,000 token context window.

### What inputs and outputs does Classify-1 support?

Classify-1 accepts text, images, and files such as PDFs as input and returns structured decisions.

### What other text models does Scaledown have?

[Summarize](https://openrouter.ai/scaledown/summarize) and [Extract](https://openrouter.ai/scaledown/extract) are other text models from Scaledown.

### When was Classify-1 released?

Classify-1 was released on October 13, 2026.

[Summarize

Summarize is an abstractive summarization model from ScaleDown. It condenses long text and documents into a fluent, faithful rewrite rather than lifting sentences from the source, and is suited for document review, transcript digests, and RAG pre-processing where retrieved content must be shortened before reaching another model. Format, focus, language, and length are steered through the system prompt, while sampling is fixed to a configuration tuned for faithful output.

[Extract

Extract is a description-driven entity extraction model from ScaleDown. Instead of a fixed set of entity types, callers describe the fields they want in plain English through `provider.options.scaledown.entities`, and the model returns each matching span with a confidence score, character offsets, and surrounding context. It is suited for pulling structured values out of contracts, invoices, emails, and transcripts, and includes built-in OCR so scanned images and PDFs work without a separate step.
