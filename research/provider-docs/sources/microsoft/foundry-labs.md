## About Microsoft-Decision-1

AI applications do more than generate. They constantly make decisions: where a request should go, which model or tool should act, whether an output meets defined criteria, and what should happen next. Microsoft-Decision-1 is a new decision model designed for these fast, repeatable tasks. Rather than generating open-ended responses, it evaluates predefined options and returns structured decisions with confidence signals that applications can use directly.  
Built on Qwen3.5-9B and fine-tuned for fast, single-pass decision scoring, Microsoft-Decision-1 gives developers a purpose-built model for decision steps within AI applications. As AI applications become more modular, developers can use different models for different types of work. Generative and reasoning models can handle creation and complex reasoning, while Microsoft-Decision-1 can handle focused, repeatable decisions that help determine what happens next.

[Learn how to deploy Microsoft-Decision-1 in Microsoft Foundry](https://learn.microsoft.com/en-us/azure/foundry/foundry-models/how-to/use-foundry-models-microsoft-decision)

Key capabilities

* Classification: Assign inputs to defined categories, such as customer intents, feedback themes, or policy labels.
* Routing: Select the appropriate model, tool, destination, team, or workflow from a set of options.
* Evaluation and verification: Assess inputs or generated responses against defined criteria.
* Scoring and prioritization: Score or prioritize items based on defined requirements.
* Workflow control: Determine whether an application or agent should continue, retry, stop, escalate, or send a case for review.
* Confidence-aware automation: Use confidence signals to help determine when to act automatically and when additional validation is needed.
