# Introduction

> Decisions, extraction and streaming: answers your code can act on.

Sage turns text into answers your software can act on. When Sage isn't sure, the answer is `null`, so your code knows to hand off to a human.

> [card] [Decides](https://docs.levanto.ai/decision-model/quickstart.md)
>
> Text and a question in. A typed answer out.

> [card] [Extracts](https://docs.levanto.ai/extract.md)
>
> Words in. Data out.

> [card] [Streams](https://docs.levanto.ai/stream.md)
>
> The answer updates as the text arrives.

Together, they take you from what people say to what happens next: extraction fills the fields, a decision picks the move. See them on live conversations in the [playground](https://playground.levanto.ai).
