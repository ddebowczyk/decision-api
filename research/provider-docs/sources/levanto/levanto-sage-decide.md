# Agent skill

> Drop-in agent skill for Cursor and Claude.

The skill teaches your coding agent to call Sage: request shapes, handling `null`, and every decision kind.

> [card] [Download the skill](https://platform.levanto.ai/api/intelligence/skill)
>
> `levanto-sage-decide`, one Markdown file.

## Install

Save the file as `SKILL.md` in `.cursor/skills/levanto-sage-decide/` or `.claude/skills/levanto-sage-decide/`.
